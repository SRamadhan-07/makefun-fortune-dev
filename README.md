A Python program — standard library only, no network — that writes one line to /output/entry.txt: a fortune-cookie message for developers, in which the tall, dark stranger turns out to be your own code from six months ago, waiting for you at 2 a.m. The line is 97 characters, inside the competition's gate of 1 to 120 characters, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
